# Qiskit Knapsack Hackathon

## O3 Knapsack Quantum Optimization

### Project Overview
This project explores the Knapsack Optimization Problem using classical and quantum computing concepts for Qiskit Fall Fest 2026.

### Problem Statement
The Knapsack Problem involves selecting items with given weights and values while keeping the total weight within a fixed capacity and maximizing the total value.

### Work Completed
- Implemented a basic classical Knapsack example in Python.
- Tested sample item weights, values, and capacity.
- Created a basic quantum circuit and observed measurement results.
- Generated a measurement histogram.
